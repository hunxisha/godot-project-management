# Godot 工坊桌面版

下载并管理 Godot 引擎版本与导出模板、隔离并快捷打开项目、浏览官方资产市场并安装插件与素材、
一键 headless 导出游戏、为项目做完整备份 —— 现在是一个**独立桌面应用**，装完即用，无需 ZTools。

## 安装

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `GodotWorkshop-<版本>-x64-setup.exe` | 64 位；ARM 设备选 `-arm64-setup.exe` |
| macOS | `GodotWorkshop-<版本>-x64.dmg` / `-arm64.dmg` | Intel 选 x64，Apple 芯片选 arm64 |
| Linux | `GodotWorkshop-<版本>-x86_64.AppImage` | 免安装，`chmod +x` 后直接运行 |
| Linux | `godot-workshop-<版本>-amd64.deb` | Debian/Ubuntu 系 |

### 当前是免签名构建

- **Windows**：首次运行会出现 SmartScreen「未知发布者」提示 → 点「更多信息」→「仍要运行」。
- **macOS**：首次打开需**右键 → 打开**，或在「系统设置 → 隐私与安全性」中放行。
- **Linux**：无额外提示。

## 从插件版迁移

桌面版与 ZTools 插件版共用同一套渲染层与能力层，文档结构一致，因此数据可以整体搬：
在插件版「设置 → 数据导出」导出，再到桌面版「设置 → 数据导入」导入即可（反之亦然）。
项目只登记本机存在的路径，收藏与浏览历史按并集合并。

## 本版功能

七页与插件版 2.0.0 对齐：概览 / 项目 / 版本 / 文档 / 插件 / 备份 / 设置。其中：

- **版本**：官方归档 + 24h 缓存，队列式下载安装（断点续传 + 自动重试），导出模板下载/安装/卸载
- **项目**：添加/新建/删除、绑定引擎版本、收藏、备份、一键 headless 导出、`.godot` 缓存清理
- **文档**：从已装引擎一键生成**离线中文类参考**（带官方简体中文翻译）、继承树、跨版本 API 差异、
  项目脚本文档、`Ctrl+K` 全局搜索
- **插件**：官方 Asset Store 浏览与搜索、内容嗅探安装、安装预览、全库更新巡检、批量管理
- **备份**：集中管理、完整性校验、三步恢复向导、保留策略清理

桌面版相比插件版的两点差异：

- 项目页用**页内搜索框**替代 ZTools 的子输入栏
- 深浅色可**实时跟随系统**切换（插件版受限于宿主无切换回调）

## 已知限制

- 暂不支持自动更新，新版本请回本页下载
- 暂无托盘常驻与 `.godot` 文件关联（后续版本评估）
- 数据存放于系统用户数据目录下的 `godot-workshop/db.json`
